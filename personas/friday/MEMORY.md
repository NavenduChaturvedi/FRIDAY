# Memory

Seed facts for Friday — things you want her to know from the very first run.
Written by hand, folded into her prompt on every launch (capped ~2500 chars).

Her *living* memory — everything she picks up as you talk to her, via
"Friday, remember that…" — is separate: it's stored in `state/memory.json`
and she manages it herself with the `memory` tool. You don't edit that here.

Put durable, first-run context below as plain bullets. Leave it empty and
she just starts learning from scratch.
